# Simple Admission Counseling System (Java Console Project)

This is a beginner-friendly Java project that simulates a simple admission
counseling system. Students are allotted courses based on available seats.

## 🌟 Features
- Student class with name, rank, and allotted course
- Course class with seat management
- Allotment based on seat availability
- Clean console output

## 🧰 Technologies Used
- Core Java
- OOP Concepts (Classes, Objects)
- Arrays
- Basic Logic
